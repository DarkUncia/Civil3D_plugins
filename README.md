# Плагин Civil3D_plugins (Озеленение и не только)

Данный репозиторий содержит набор инструментов и команд для автоматизации работы в Autodesk Civil 3D (версия 2025 и совместимые).

## 🛠 Текущие возможности

### 1. Экспорт данных и координат
*   **`CoordinateExporter`** — выгрузка координат точек.
*   **`C3D_ExportClasses`** — экспорт классов и данных.
*   **`CogoFromGeometryCommands`** — создание точек COGO из геометрии.

### 2. Автоматизация озеленения (Flora)
Добавлены инструменты для быстрого заполнения наборов характеристик (Property Sets) на основе данных из Excel (FloraBIM).

*   **`FLORA_FILL_PROPERTIES`** (Для блоков: Деревья и Кустарники)
    *   Ищет блоки на чертеже по их имени (с учетом динамических блоков).
    *   Находит соответствующие строки в Excel по ID/Имени.
    *   Навешивает набор характеристик **"01_Деревья и кусты (стандарт)"**.
    *   Заполняет Коды классификаторов, Наименование, Статус, Тип и все размеры (xxxs...xl).

*   **`FLORA_HATCH_FILL_PROPERTIES`** (Для площадных объектов: Штриховки, 3D-тела, Поверхности)
    *   Ищет объекты по их **RGB-цвету** (True Color) или цвету слоя.
    *   Находит соответствующие строки в Excel по колонке `color`.
    *   Навешивает набор характеристик **"02_Живая изгородь. Многолетние цветы. Злаки. Миксы"**.
    *   Заполняет все текстовые параметры, включая `color`, `color_AGO`, тип растения, размеры и образец штриховки.

## 🚀 Как пользоваться

1. Скомпилируйте решение (Платформа обязательно **x64**).
2. Загрузите полученную DLL в Civil 3D через команду `NETLOAD`.
3. В командной строке введите нужную команду (`FLORA_FILL_PROPERTIES` или `FLORA_HATCH_FILL_PROPERTIES`).
4. Выберите Excel-файл с ведомостью озеленения.
5. Выберите объекты на чертеже. Плагин автоматически подтянет данные и заполнит Наборы Характеристик.

## ⚠️ Требования
*   Autodesk Civil 3D 2025 (или совместимая версия).
*   .NET Framework 4.8.
*   Наличие в чертеже (DWG) заранее настроенных Наборов Характеристик (`01_Деревья...` и `02_Живая изгородь...`).
*   Для площадных объектов цвет в AutoCAD должен строго совпадать с колонкой `color` в Excel.

## 📦 Зависимости
Проект использует библиотеку **ExcelDataReader** для чтения файлов `.xlsx`.
