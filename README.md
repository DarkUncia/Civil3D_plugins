# Civil3D Plugins & BIM Utilities

Набор автоматизированных инструментов и плагинов для среды **Autodesk AutoCAD / Civil 3D**, написанный на C# .NET. Плагины предназначены для аудита структуры чертежей, полуавтоматической верификации геометрии с генерацией COGO-точек, а также для высокоточного экспорта систем координат для последующей BIM-координации (Revit, Dynamo, Navisworks).

---

## 🚀 Основной функционал и команды

### 1. Модуль аудита и экспорта данных геометрии (`C3D_ExportClasses`)
Предназначен для быстрого тестирования окружения и глубокого анализа структуры слоев элементов.

*   **`C3D_ExportData`** — базовая проверочная команда. Генерирует текстовый отчет `C3D_Report.txt` на Рабочем столе пользователя, фиксируя имя активного чертежа и время теста. Используется для верификации корректности загрузки плагина и прав доступа.
*   **`C3D_AnalyzeLayers`** — инструмент детального аудита чертежа. Позволяет выбрать рамкой любые объекты, анализирует их тип, уникальный `Handle`, слой и контейнер-владелец (`BlockTableRecord`, пространство модели/листа). Выгружает структурированную таблицу `C3D_Deep_Analysis.txt` на Рабочий стол.

### 2. Модуль верификации отметок и создания COGO-точек (`CogoFromGeometryCommands`)
Автоматизирует рутинный процесс создания COGO-точек Civil 3D на основе плоских или объемных объектов чертежа.

*   **`CreateCogoSmartVerify`** — интеллектуальный парсер геометрии. 
    *   **Окружности (CIRCLE):** Если окружность имеет физическую координату `Z > 0`, плагин считывает её и создает в этой точке `CogoPoint` с описанием `Circle_GeometricZ`.
    *   **Штриховки (HATCH):** Если выбрана плоская штриховка, плагин сканирует пространство в радиусе 1 метра от её центра, находит текстовые элементы (`TEXT / MTEXT`), очищает их регулярными выражениями от служебных тегов форматирования и парсит числовое значение (высоту). Штриховке присваивается эта отметка, и создается COGO-точка с описанием `Hatch_TextZ`.
    *   **Контроль дубликатов:** Перед созданием точки плагин проверяет существующую базу чертежа в координатах XY. Старые дубликаты автоматически перезаписываются.
    *   **Фильтрация ошибок:** Объекты, у которых не удалось определить высотную отметку (или она равна 0), автоматически переносятся на сервисный слой `_АНАЛИЗ_ОШИБОК` и окрашиваются в красный цвет для ручного контроля инженером.

### 3. Модуль координации и выгрузки XML (`CoordinateExporter`)
Обеспечивает точную передачу локальных систем координат проекта в стороннее BIM-ПО.

*   **`ExportProjectCoordinates`** — выгрузка параметров посадки зданий.
    *   Пользователь выбирает папку для сохранения через стандартный диалог Windows.
    *   Плагин фильтрует выборку, оставляя на чертеже только специфичные блоки с именем `КЛЕН_Базовая точка проекта`.
    *   Из блока считывается атрибут `НОМЕР_ДОМА` для формирования безопасного имени файла: `Код проекта_Очередь_{НомерДома}.xml` (с авторазрешением конфликтов одинаковых имен).
    *   В XML-файл записываются координаты вставки блока (`OriginX`, `OriginY` с максимальной точностью `G17`, `OriginZ` с точностью `F2`) и угол поворота (`RotationInXYPlane` в радианах, `G17`), что соответствует стандартам передачи данных в Dynamo/Revit. По завершении папка экспорта автоматически открывается в Проводнике.

## 🛠 Установка и запуск

### Требования
*   Установленный **Autodesk AutoCAD / Civil 3D** (рекомендуется версия с поддержкой актуального .NET API).
*   Библиотека скомпилирована под архитектуру `x64`.

### Пошаговая инструкция
1. Скомпилируйте проект в Visual Studio (в режиме *Release* или *Debug*).
2. Запустите Civil 3D / AutoCAD и откройте целевой чертеж.
3. Введите в командную строку AutoCAD команду **`NETLOAD`** и нажмите `Enter`.
4. В открывшемся окне выберите скомпилированную библиотеку `Civil3D_plugins.dll`.
5. Запустите любую из команд выше (например, `CreateCogoSmartVerify` или `ExportProjectCoordinates`), введя её название напрямую в консоль чертежа.
