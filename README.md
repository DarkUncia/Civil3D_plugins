# Civil3D_plugins: Модуль автоматизации штриховок озеленения (FloraHatch)

Изолированный плагин для **Autodesk Civil 3D 2025/2026** (.NET 8.0), предназначенный для пакетной привязки и сквозного наполнения наборов характеристик (*Property Sets*) элементов благоустройства: живых изгородей, цветников, злаков и миксов на основе ведомостей Excel.

---

## 🚀 Ключевые возможности

* **Zero-COM Бинарный Парсинг:** Чтение таблиц `.xlsx` происходит через быстродействующий поток `FileStream` с помощью библиотеки `ExcelDataReader` без необходимости установки Microsoft Excel на ПК инженера.
* **Умное распознавание структуры таблиц:** Плагин динамически находит целевые колонки по их заголовкам (включая регистронезависимый поиск `color`, `id`, `наименование`, `штриховка` и размерных линеек от `xxxs` до `xl`).
* **Раздельный учет цветов:** 
  * Строго сканирует оригинальную колонку `color` (столбец 14) для создания уникального RGB-ключа поиска штриховки на чертеже.
  * Честно извлекает и транслирует данные из колонки `color_AGO` (столбец 15) в соответствующее поле набора характеристик.
* **Инженерный фильтр данных:** Автоматически наглухо блокирует и пропускает 2-ю строку таблицы, зарезервированную под текстовые подсказки и примеры для человека.
* **Автоматическое насаждение PSD:** Если на выбранный контур штриховки еще не назначен Property Set, плагин программно инициализирует его во время транзакции, освобождая инженера от рутинных кликов.
* **Рефлексивная защита свойств:** Метод записи устойчив к человеческому фактору — плагину не важен регистр букв или случайные скрытые пробелы в именах параметров внутри Диспетчера стилей Civil 3D.

---

## 🛠️ Архитектура и стек технологий

* **Платформа:** `.NET 8.0-windows` (под актуальные версии Civil 3D / AutoCAD API).
* **Базовые зависимости AutoCAD:** `AccgCoreMgd.dll`, `AecPropDataMgd.dll`, `AutoCADMgd.dll`.
* **NuGet-пакеты:** `ExcelDataReader` (v3.7.0), `System.Text.CodePages` (для корректной кодировки кириллицы).

## 📦 Инструкция по развертыванию и запуску

### 1. Компиляция проекта
Откройте решение в Visual Studio или JetBrains Rider и выполните пересборку проекта:
* Конфигурация: `Debug` или `Release`
* Платформа: `x64`

### 2. Загрузка в Civil 3D
1. В консоли Civil 3D введите команду `NETLOAD`.
2. Поочередно подгрузите зависимость библиотеки `ExcelDataReader.dll` из папки вывода сборки, а затем непосредственно сам плагин — `Civil3D_plugins.dll`.

### 3. Синхронизация данных
1. Запустите плагин командой:
   ```text
   FLORA_HATCH_FILL_PROPERTIES
   ```
2. В появившемся диалоговом окне выберите актуальный файл базы данных Excel.
3. Выберите рамкой контуры штриховок (`Hatch`) на чертеже. 
4. Плагин автоматически сверит RGB-цвет каждой штриховки с базой, создаст связь и наполнит целевой набор характеристик:  
   **`02_Живая изгородь. Многолетние цветы. Злаки. Миксы`**

## 📋 Логирование и диагностика

При запуске плагин выводит в консоль развернутый лог отладки:
* Общее число импортированных из Excel RGB-ключей.
* Превью первых 10 позиций для визуального контроля сопоставления.
* Точный разбор каждой обрабатываемой штриховки по её уникальному дескриптору (`Handle`) с указанием статуса сопоставления `[Матч! Данные найдены в Excel]` или `[Пропуск]`.
