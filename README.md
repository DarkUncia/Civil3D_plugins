# Civil3D Plugins & BIM Utilities

Набор автоматизированных инструментов и плагинов для среды **Autodesk AutoCAD / Civil 3D** (версии 2025/2026), написанный на C# (.NET 8.0). Предназначен для аудита структуры чертежей, автоматизации рутинных операций, создания COGO-точек и подготовки моделей к BIM-координации (Revit, Dynamo, Navisworks).

---

## 🚀 Основной функционал и команды

### 1. Синхронизация данных МАФ с Excel
**Команда:** `TEST_FILL_MAF`
*   Пакетное считывание ведомостей малых архитектурных форм (МАФ) из таблиц Excel и автоматическое заполнение Наборов характеристик (Property Sets) `07_МАФ` у блоков на чертеже.
*   **Архитектура Zero-Graphics**: Чтение файлов через библиотеку `ExcelDataReader` в виде бинарного потока `FileStream`. Это полностью исключает конфликты со шрифтами Civil 3D.
*   **Динамическая привязка**: Если набор характеристик отсутствует на блоке, плагин автоматически инициализирует и назначает его объекту.

### 2. Модуль аудита и экспорта геометрии (`C3D_ExportClasses`)
*   **`C3D_ExportData`** — базовая проверка окружения. Генерирует текстовый отчет `C3D_Report.txt` на Рабочем столе пользователя с фиксацией имени активного чертежа.
*   **`C3D_AnalyzeLayers`** — детальный аудит объектов. Анализирует тип элементов, уникальный `Handle`, слой и контейнер-владелец (`BlockTableRecord`). Выгружает структурированную таблицу `C3D_Deep_Analysis.txt` на Рабочий стол.

### 3. Верификация отметок и создание COGO-точек (`CogoFromGeometryCommands`)
*   **`CreateCogoSmartVerify`** — интеллектуальный парсер плоских и объемных объектов:
    *   **Окружности (CIRCLE):** Считывает физическую координату `Z > 0` и создает `CogoPoint` с описанием `Circle_GeometricZ`.
    *   **Штриховки (HATCH):** Сканирует текстовые элементы (`TEXT / MTEXT`) в радиусе 1 метра от центра штриховки, извлекает числовое значение высоты и создает COGO-точка с описанием `Hatch_TextZ`.
    *   **Контроль ошибок:** Объекты без отметки автоматически переносятся на сервисный слой `_АНАЛИЗ_ОШИБОК` и окрашиваются в красный цвет. Дубликаты XY перезаписываются автоматически.

### 4. Модуль координации и выгрузки XML (`CoordinateExporter`)
**Команда:** `ExportProjectCoordinates`
*   Выгрузка параметров посадки зданий на основе специфичных блоков `КЛЕН_Базовая точка проекта`.
*   Считывает атрибут `НОМЕР_ДОМА` и формирует файл вида `Код проекта_Очередь_{НомерДома}.xml`.
*   Записывает координаты вставки (`OriginX`, `OriginY` с точностью `G17`, `OriginZ` с точностью `F2`) и угол поворота в радианах для прямой передачи в Revit/Dynamo.

## 📊 Требования к структуре Excel для МАФ

Первая строка (шапка) файла Excel обязательно должна быть заполнена на латинице в нижнем регистре. Сопоставление блоков происходит по колонке `guid` (имя блока на чертеже).

Ожидаемые заголовки колонок:
`guid`, `id`, `manufacturer`, `name`, `dimensions`, `note`, `type`, `type2`, `weight`, `group_id`, `version`, `adsk_name`, `adsk_set_of_drawings`, `acer_codecollision`, `krtrs_code_by_classifier`.

## 🛠 Настройка проекта в Visual Studio

Конфигурация файла проекта **`.csproj`**:
```xml
<PropertyGroup>
  <TargetFramework>net8.0-windows</TargetFramework>
  <Platforms>AnyCPU;x64</Platforms>
  <CopyLocalLockFileAssemblies>true</CopyLocalLockFileAssemblies>
</PropertyGroup>

<ItemGroup>
  <PackageReference Include="ExcelDataReader" Version="3.7.0" />
</ItemGroup>
```

---

## 💻 Инструкция по запуску

1. Скомпилируйте проект в Visual Studio под платформу **`x64`**.
2. В консоли Civil 3D введите команду **`NETLOAD`**.
3. Загрузите сначала зависимость **`ExcelDataReader.dll`**, а затем сам плагин **`Civil3D_plugins.dll`** из папки сборки.
4. Запустите любую команду плагина напрямую через консоль чертежа (например, `TEST_FILL_MAF` или `CreateCogoSmartVerify`).
